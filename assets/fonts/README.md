# Offline report fonts

Unmodified Noto Sans Regular/Bold and Noto Sans Math Regular TrueType fonts from the official archived
[Noto fonts repository](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans).
Redistributed under SIL Open Font License 1.1; see OFL.txt (also bundled in the app).
These assets cover Latin, Cyrillic and the report's measurement/punctuation symbols.
Noto Sans Math supplies the approximation symbol used by imperial formatting.
They are not a universal font for every script or emoji.
